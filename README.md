# TikTok Telegram Bot 🤖📥

ئەو بوتەی TikTok Telegram Bot کە کامڵە و هەموو شت بەدووگمە و AI emoji هەیە:

- 📥 Download TikTok Videos بدون yt-dlp و بدون API
- 🎵 Download Audio
- ⚙️ Admin Panel بەدووگمە
- 🌐 Force Join بۆ دوو جەنال
- 🏷️ پشتیوانی 10 زبان
- 🔔 نوتیفیکەیشن بۆ خاوەن بوت
- 🤖 AI emoji captions

---

## 🛠️ پێویستەکان
- Python 3.10+  
- Pyrogram: `pip install pyrogram tgcrypto`  
- Requests: `pip install requests`
